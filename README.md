# BlueGay

BlueGay is a customizable Windows desktop IDE with ChatLGBT, Code Together, and French (Canada) interface support.

## Download

Download the Windows executable from [the latest release](https://github.com/ReviveRC/BlueGay/releases/latest). The first updater-enabled release is version 1.0.0; close older copies before opening it.

## Updates

Version 1.0.0 checks this repository for signed updates automatically. Newer releases download in the background; choose **Restart to update** when your work is saved. Manual checks are available under **Help → Check for updates**.

Release assets include the executable, a signed `latest.jwt` update manifest, and SHA-256 checksums.
