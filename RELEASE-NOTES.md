# BlueGay 1.0.6

BlueGay is an **unofficial parody of BlueJ IDE**, independent of and unaffiliated with the BlueJ project.

- **Faster Code Together:** the editor checks for updates about four times per second and sends changed files. Saving one file no longer delays updates to other files. Use this build on both computers for the faster sync.
- **VS Code settings import:** preview and apply supported settings from your VS Code user settings.json. Find it in the first-launch prompt or Preferences.
- **ZIP export:** export original binary files, current editor text, and empty folders together.
- **ChatLGBT:** the active ChatGPT session renews in the background. Temporary failures preserve saved accounts. The AI panel shows reported API request and token limits and links to the remaining ChatGPT plan allowance.

Download **BlueGay-1.0.6.exe** or use **Help → Check for updates** in an existing updater-enabled build.
